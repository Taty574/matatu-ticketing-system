Functional Requirements: Matatu Ticketing System
1. Purpose
This section defines the specific capabilities, end-to-end workflows, and system features required of the Matatu Ticketing System. 
It covers passenger booking and fare calculation, conductor ticket validation, M-Pesa/cash payment processing, real-time fleet tracking, and automated SACCO revenue settlement within Nairobi  operations. 
The system is at the requirements stage, so every capability detailed below represents a proposed functional requirement designed to digitize manual stage and on-board operations.
